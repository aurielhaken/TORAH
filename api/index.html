5 Méthodes Kabbalistiques

📊 Guématrie

גימטריא

Calcul des valeurs numériques de chaque lettre hébraïque. Révèle des connexions spirituelles entre mots de même valeur.

Exemple : א=1, ב=2... ת=400

🔍 ELS

Equidistant Letter Sequences

Recherche de mots dont les lettres apparaissent à intervalles réguliers. Méthode des "Bible Codes".

Exemple : Chercher תורה avec intervalle 7

📝 Notarikon

נוטריקון

Acronymes et expansions sacrés. Chaque lettre peut devenir un mot entier.

Exemple : אמן = אל מלך נאמן

🔄 At-Bash

אתב״ש

Substitution symétrique des lettres (א↔ת, ב↔ש). Chiffrement hébraïque ancien.

Exemple : בבל → ששך (Jérémie 25:26)

🔀 Témourah

תמורה

Permutations et rotations de lettres pour révéler de nouvelles significations.

Exemple : אור → ראו (Lumière → Voyez)
